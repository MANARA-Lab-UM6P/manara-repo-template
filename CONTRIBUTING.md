# Contributing to this Repository

This repository is part of MANARA Lab (Multimodal AI, Networks, Analytics, Recommender Systems & Augmented Sensing Laboratory) at UM6P College of Computing.

## Guidelines

- All code must be documented and reproducible
- Follow the repo structure defined in README.md
- Always include a requirements.txt or environment.yml
- Link every experiment script to its corresponding result
- Never commit large data files directly — use download scripts or Zenodo links instead
